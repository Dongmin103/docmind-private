# DOCMIND 설치 시작 안내

처음 설치하실 때에는 저장소 폴더의 **[시작안내.html](../시작안내.html)**을 브라우저로 열어 주세요. 인터넷 연결 없이도 안내 화면을 보실 수 있습니다. 실제 설치와 답변 서비스에는 아래의 네트워크 연결이 필요합니다.

## 먼저 준비해 주세요

- Windows x64, PowerShell 7, Python 3.11 이상, Git을 준비해 주세요.
- WSL2의 Linux Docker 또는 Docker Desktop의 Linux 엔진과 Docker Compose v2가 실행되어 있어야 합니다. 실행 이미지는 `linux/amd64`용입니다.
- 승인된 `uEncryptor2.exe`와 해당 서버의 인증서·라이선스를 준비해 주세요. 복호화 수집기는 Windows에서 실행합니다.
- 설치 계정으로 문서 폴더나 파일서버 공유 폴더를 읽을 수 있는지 확인해 주세요.
- PRIVATE 저장소 및 이미지 파일, 설치용 Python 패키지, 기존 답변 API와 Jina API에 접속할 수 있어야 합니다. 불러온 실행 이미지는 약 20 GB이며 다운로드 파일과 새 색인을 위한 공간도 필요합니다.

환경 준비가 필요하시면 서버 관리 담당자와 함께 확인해 주세요. 자세한 기술 기준은 [배포 인수인계 문서](AGENT-HANDOFF.md)에 정리되어 있습니다.

## 1. 문서 폴더를 입력해 주세요

저장소 폴더의 **`Open-SourceFolders.cmd`를 두 번 클릭**하시면 메모장으로 실제 설정 파일이 열립니다. **`deployment/source-folders.txt` 한 파일만 수정**하시면 됩니다.

목록은 Docker 이미지 밖의 파일입니다. 설치기가 Windows 수집기의 외부 설정으로 반영하므로 폴더 주소를 바꾸실 때 이미지를 수정하거나 다시 빌드하지 않습니다.

```text
D:/dept2
E:/계약서
//fileserver/share/Department
```

위 주소는 예시입니다. 실제 문서가 있는 주소로 바꾸어 주시고, **한 줄에 폴더 하나씩** 적어 저장해 주세요. 여러 폴더를 함께 등록하실 수 있습니다. 주소를 적는 순서는 상관없습니다. [폴더 주소 예시 파일](source-folders.examples.txt)은 참고용이며 설치기가 읽는 설정 파일은 아닙니다.

파일서버의 `D:` 드라이브는 설치 서버의 `D:` 드라이브와 다릅니다. 다른 서버의 폴더라면 `//fileserver/share/Department`처럼 공유 주소를 적어 주세요.

## 2. 설치 파일을 실행해 주세요

저장소 폴더의 **`Install-DocMind.cmd`를 관리자 권한으로 실행**해 주세요. 기존 운영 DOCMIND를 기준으로 준비한 CPU용 실행 이미지를 내려받아 Docker에 불러오고 필요한 설정을 자동으로 적용합니다.

- 소스 코드를 다시 빌드하거나 Hugging Face에서 모델을 새로 다운로드하지 않습니다.
- CPU 인덱싱, OCR 끄기, 기존 API 설정과 자동 공용 접속을 적용합니다.
- 기존 설정과 복호화 키는 PRIVATE 저장소에 포함되어 있습니다. API 키나 비밀번호를 다시 입력하실 필요가 없습니다.
- 기존 운영 문서·벡터 DB는 가져오지 않으며 새 문서 폴더에서 인덱싱을 시작합니다.

이미지 다운로드와 불러오기가 끝날 때까지 창을 닫지 말아 주세요. 오류가 발생하면 표시된 내용을 확인해 환경·권한·네트워크 문제를 해결하신 뒤 같은 설치 파일을 다시 실행해 주세요. 기존 Docker 데이터나 생성된 설정을 임의로 지우실 필요는 없습니다.

같은 버전의 이미지가 이미 준비되어 있으면 다음 실행부터는 재사용합니다.

## 3. 화면을 열고 문서 한 개로 확인해 주세요

설치 서버의 브라우저에서 **[http://localhost:18080](http://localhost:18080)**을 열어 주세요. 이메일·비밀번호 입력 없이 공용 작업공간에 바로 접속합니다. 다른 PC에서 접속하실 주소는 배포 담당자가 연결한 주소를 사용해 주세요.

1. 등록한 폴더의 텍스트 PDF 한 개가 목록에 나타나는지 확인해 주세요.
2. 인덱싱이 완료된 뒤 문서 내용으로 검색하고 질문해 주세요.
3. 답변과 근거 문서, 원문 미리보기를 확인해 주세요.
4. 배포 담당자와 함께 임시 복호화 파일이 정리되는지 확인해 주세요.

OCR을 사용하지 않으므로 글자가 이미지로만 들어 있는 스캔 문서는 이 확인에 사용하지 말아 주세요.

## 나중에 폴더를 추가하거나 제외하실 때

동일한 **`deployment/source-folders.txt`**에서 주소를 추가하거나 제외해 저장하신 뒤 **`Install-DocMind.cmd`를 다시 실행**해 주세요. 폴더 목록을 반영하는 동안 수집 작업이 잠시 재시작될 수 있습니다. 기존 폴더의 주소 순서만 바꾸어도 같은 폴더로 구분합니다.

진행 중인 처리와 임시 파일 정리가 끝난 뒤 목록을 반영합니다. 제외한 폴더는 수집과 활성 목록에서 빠지며 원본 파일이나 기존 색인은 삭제하지 않습니다. 같은 주소를 다시 추가하시면 기존 폴더 정보에 연결합니다.

이 PRIVATE 자료에는 운영 접속 설정이 포함되어 있으므로 승인된 배포 담당자에게만 전달해 주세요.
