새 서버 설치 시작 안내

폴더 주소를 적고,
설치 파일을 실행해 주세요.

수정하실 설정은 문서 폴더 목록 한 파일뿐입니다. CPU 실행과 기존 API 설정은 자동으로 적용됩니다. 아래 순서대로 준비하시면 됩니다.

  1. 1준비 확인
  2. 2폴더 입력
  3. 3설치 실행
  4. 4문서로 확인
1

서버 준비 상태를 확인해 주세요.

환경 준비가 필요하시면 서버 관리 담당자와 함께 확인해 주세요.

실행 이미지는 Linux x86_64용이며 Windows 호스트의 복호화 수집기와 함께 사용합니다. Linux 전용 서버에 Windows 수집기 없이 설치하는 절차는 아닙니다. 이 체크 표시는 수동 확인용이며 서버를 자동 검사하지 않습니다.

2

문서 폴더를 한 줄에 하나씩 적어 주세요.

여러 폴더를 함께 등록하실 수 있습니다. 입력 순서는 상관없습니다.

받으신 DOCMIND 폴더에서 다음 파일을 두 번 클릭해 주세요.

Open-SourceFolders.cmd

메모장으로 열린 deployment/source-folders.txt에 실제 문서 폴더 주소를 적으신 뒤 저장해 주세요.

D:/dept2
E:/계약서
//fileserver/share/Department

위 주소는 예시입니다. 실제 존재하는 폴더 주소로 바꾸어 주세요. 다른 파일서버에 있는 폴더는 해당 서버의 D:가 아니라 //서버이름/공유이름/폴더 형식으로 적어 주세요.

예시 파일 보기

예시 파일은 참고용입니다. 실제 수정하실 파일은 deployment/source-folders.txt 한 파일입니다.

3

설치 파일을 관리자 권한으로 실행해 주세요.

파일을 마우스 오른쪽 버튼으로 클릭하신 뒤 ‘관리자 권한으로 실행’을 선택해 주세요.

Install-DocMind.cmd
준비된 실행 이미지
다운로드·불러오기
CPU 인덱싱 · OCR 끄기
기존 API 자동 적용
새 색인과 작업공간
수집·감시 작업 시작

기존 운영 DOCMIND를 기준으로 준비한 CPU용 실행 이미지를 사용합니다. 소스 코드를 다시 빌드하거나 Hugging Face에서 모델을 별도로 받지 않습니다. 기존 설정과 복호화 키도 PRIVATE 자료에 포함되어 있으므로 API 키나 비밀번호를 다시 입력하실 필요가 없습니다.

이미지 파일이 커서 다운로드와 불러오기에 시간이 걸릴 수 있습니다. 완료 메시지가 나올 때까지 설치 창을 닫지 말아 주세요.

다음 실행부터는 같은 버전의 이미지가 준비되어 있으면 다시 받지 않고 재사용합니다.

설치 중 오류가 보이시면

표시된 오류를 확인해 Docker 실행 상태, 문서 폴더 접근 권한, 네트워크와 디스크 공간을 점검해 주세요. 원인을 해결하신 뒤 같은 설치 파일을 다시 실행하시면 됩니다. 기존 설정이나 Docker 데이터를 임의로 지우지 말아 주세요.

4

화면을 열고 문서 한 개로 확인해 주세요.

설치한 서버의 브라우저에서 아래 주소를 열어 주세요.

DOCMIND 열기 · localhost:18080

이메일·비밀번호 입력 없이 공용 작업공간에 바로 접속합니다. 다른 PC에서는 배포 담당자가 연결한 접속 주소를 사용해 주세요.

  1. 등록한 폴더의 텍스트 PDF 한 개가 문서 목록에 나타나는지 확인해 주세요.
  2. 인덱싱이 끝나면 문서 내용으로 검색하고 질문해 주세요.
  3. 답변과 근거 문서, 원문 미리보기를 확인해 주세요.
  4. 배포 담당자와 함께 임시 복호화 파일의 정리 여부를 확인해 주세요.

기존 운영 문서·벡터 DB는 가져오지 않습니다. 새 폴더의 문서로 색인을 만듭니다. OCR을 사용하지 않으므로 이미지로만 된 스캔 PDF 대신 텍스트가 포함된 PDF로 확인해 주세요.

나중에 폴더를 추가하거나 제외하실 때

Open-SourceFolders.cmd로 같은 폴더 목록 파일을 여신 뒤 주소를 수정·저장해 주세요. 이어서 Install-DocMind.cmd를 다시 실행하시면 목록을 반영합니다. 이 과정에서 수집 작업이 잠시 재시작될 수 있습니다.

폴더를 적는 순서가 달라져도 같은 주소는 같은 폴더로 구분합니다. 모델·API 키·내부 계정 설정은 변경하실 필요가 없습니다.

진행 중인 문서 처리와 임시 파일 정리가 끝난 뒤 목록을 반영합니다. 제외한 폴더는 수집과 활성 목록에서 빠지며 원본이나 기존 색인은 삭제하지 않습니다. 같은 주소를 다시 추가하시면 기존 폴더 정보에 연결합니다.
