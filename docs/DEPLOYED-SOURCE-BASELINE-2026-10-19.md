사용자 지시에 따라 **실행 중인 배포 파일을 기준**으로 이전했다. 브랜치의 커밋 개수나 작성 날짜를 최신 여부의 근거로 삼지 않았다. 기존 서비스·예약 작업·DB·검색 색인은 변경하지 않았다.

기존 API 키와 실제 환경설정은 Git 소스에 추가하지 않았다. 별도 AES-256-GCM 암호화 릴리스 첨부파일로 보존했다. JSON 증거에는 파일 경로·해시·건수만 기록했다.

`docs/DEPLOYED-SOURCE-BASELINE-2026-10-19.json`은 파일별 대조 결과다. `deployment/host-roles/`는 원래 역할별 바이트를 보존하며, 원래 PC의 경로를 참조하는 launcher도 포함한다. 새 서버에서 경로를 수정하지 않고 바로 실행하는 설치 프로그램은 아니다.

## 검증 범위

- 서버 Python 289개와 역할별 실행 소스 58개를 SHA-256으로 검증한다.
- 키·설정 암호화의 인증 태그와 복호화 후 각 파일 해시를 검증한다. 실제 API 키 문자열이 새 소스 파일에 포함되지 않았는지 값 대조 검사를 수행한다.
- 제품에서 제거한 catalog runtime 재유입 검사를 수행한다.
- React/TypeScript 소스는 공개 브랜치의 소스를 보존한다. 컴파일된 웹 자산만으로 그 원본 소스의 완전한 동일성을 증명하지 않는다. 실제 컨테이너 웹 자산도 암호화 첨부파일에 별도 보존한다.
- 이번 이전은 프로그램 수정·실서비스 재배포·새 서버 전체 실행 시험이 아니다.
